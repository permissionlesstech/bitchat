# Nearsend Chat iOS (early development)
SwiftUI app, iOS 17+. Currently UI + simulated peers; `MeshTransport` is where CoreBluetooth/Noise goes.

    brew install xcodegen && xcodegen generate && open NearsendChat.xcodeproj

Or push to GitHub: `.github/workflows/ios.yml` builds on a macOS runner (no Mac needed).
Not yet compiled by the author; expect small fixes on first build.
